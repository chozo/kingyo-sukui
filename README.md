# 金魚すくい

**金魚以外がすくえることも・・・**

▶ 遊ぶ：https://game.chozo.net/kingyo-sukui/ （スマホ・PCのブラウザ）

水の中には黒い魚影しか見えない。3枚のポイですくい上げると画面が切り替わり、正体が重さと説明つきで3Dで現れる。金魚かもしれないし、フナや鯉、ハズレの空き缶かもしれない。ほかに何がいるかは、すくってのお楽しみ。60秒。

Notion「Mini Web Game Idea」一意キー `2026-10-11-0300-02` をもとに制作。

## 遊び方

- 狙う：画面のどこを押してもよく、ドラッグした分だけポイが水面の上を動く（相対移動）。空中では紙は減らず、紙が透けて下の影と着水位置の輪が見える。
- 入れる：指を離すと、その場所でポイが水に入る。
- すくう：もう一度タップするとすくい上げる。押したままドラッグすれば水中で追いかけられ、離すとすくう。
- すくった後や新しいポイに替わった後は、その場の上空で待機する。
- すくえると水しぶきと光のあとで正体画面になる（3Dの実物、名前、重さ、説明、点数）。タップでつづける。正体画面の間は時間が止まる。
- 紙の強さは150。水中で毎秒5、水槽幅0.3/秒より速く動かすとさらに毎秒20以上減る。すくった物の「紙の消費」が残りより大きいと破れ、正体だけ見せて逃げられる（ポイが1枚減る）。
- 1回にすくえるのは1つ。判定（紙の半径の85%）に複数入っているときは、ポイの中心に一番近いものをすくう。
- 音：「はじめる」を押すとBGMが流れる。正体画面では少し小さくなり、結果画面とタイトルでは止まる。右下の音ボタンでBGMと効果音をまとめてON/OFF（次回も覚えておく。正体画面では文字に重なるので隠す）。タブを隠すと音も止まる。
- 途中で大きな影が入ってくることがある。すくった影は2.5秒後にランダムな正体の影で補充される。

## 仕組み

- Three.js（0.180.0）。画像素材は使わず、魚・ハズレ・水槽・ポイ・映り込み用の景色はすべてコードで生成。
- 水面：GPUで解く高さ場の波（128×192）。水中の屈折、夜祭りの提灯の反射、裸電球のきらめきを合成。水は少し濁らせている。
- 魚影：どの正体も同じ魚形の暗い影で描き、長さと太さに少しばらつきを持たせて形だけでは見分けられないようにしている（`fishModel.ts` の `makeShadowMaterial`）。
- 正体画面：別の3D場面（`showcase.ts`）。魚は種ごとの体形と模様のモデルが跳ね、魚の形でないもの（`propModels.ts`）は回転して見せる。
- 音（`audio.ts`）：Web Audio で合成。BGMは夜祭りの祭囃子風の8小節ループ（112 BPM、陽音階の篠笛の旋律・太鼓・鉦）。外部音源は使わない。
- OGP：`public/ogp.png`（1200×630）。ゲーム画面（魚影の水槽と、すくい上げた金魚の正体画面）とタイトルを並べたもの。`node tools/create-ogp.mjs`（開発サーバー起動中に実行）で作り直せる。
- 深さ：水の屈折で浅く見える分（3/4）を描画に反映し、すくう判定は「画面上で水面のどこに見えているか」で行う。

## 開発

```sh
npm install
npm run dev        # http://127.0.0.1:5173
npm run build      # dist/kingyo-sukui/
npm run deploy     # ビルドして Cloudflare Workers へ公開
node tools/e2e.mjs # 実際のマウス操作での確認（GAME_URL で接続先を指定）
node tools/shots.mjs [title play reveal tear]  # 確認用スクリーンショット → artifacts/
node tools/create-ogp.mjs  # OGP画像 → public/ogp.png
```

## 告知動画

```sh
npm run promo                      # ビルドして全コマを撮影し、MP4 を書き出す（1分弱）
PROMO_EVERY=15 npm run promo       # 確認用: 15コマおきの一覧画像だけ作る
PROMO_ENCODE_ONLY=1 npm run promo  # 撮り直さずに書き出しだけやり直す
```

- 出力：`../video/kingyo-sukui-promo.mp4`（1080×1920、30fps、約29秒、-18 LUFS）、表紙 `-promo-cover.jpg`（金魚の正体画面）、一覧 `-promo-sheet.jpg`。動画はリポジトリに含めない。
- 台本は `tools/promo/scenario.js`、見た目は `tools/promo/promo.css`（夜祭りの背景）。撮影・書き出しは `record.mjs` / `stage.js`。
- すくって正体を見せるのは金魚・フナ・空き缶・鯉だけ。ほかの正体はシークレットなので映さない（最後の大きな影はすくわずに終える）。
- 音はゲーム本体の効果音と祭囃子のBGMを、撮影した時刻に合わせて書き出す（`__game.audio.capture` / `drain` / `render` / `cue` / `mix`）。外部の音源は使わない。BGMを小さめに聞かせるため全体は -18 LUFS（`config.loudness`）、効果音は `audio.mix(0.4)`、BGMは `cue('bgm', 秒, 0.2)` で控えめにしている。

確認用の入口 `window.__game`（`start` / `manual` / `step` / `press` / `move` / `release` / `touchDown` / `touchMove` / `touchUp` / `next` / `spawn` / `holdFish` / `state` / `sound` / `drainEvents` / `audio` など）。

## 確認結果（2026-10-11、Mac の Chrome ヘッドレス）

- e2e：どこを押してもドラッグで空中を動き、空中では紙が減らない／離すと狙った場所に入り、タップですくう（空振りならその場で待機）／水中で速く動かすと紙が早く減る／判定に2つ入ると近いほうだけすくい、遠いほうは水に残る／すくうと正体画面になり、表示直後のタップは無視、その後のタップで戻る／ハズレ（空き缶）は0点／弱った紙では大物で破れ「逃げられた」と正体を見せて水へ戻る／新しい紙なら大物もすくえる／水中のまま時間切れになるとその場ですくってから結果画面／BGMはタイトルで鳴らず、はじめると流れ、結果画面で止まり、もう一度で再開／音ボタンで消せて、再読み込み後も覚えている／360×640・390×844・1440×900ではみ出さない。3回連続で成功（告知動画の撮影用の入口を足した後も成功）。
- 描画速度：60fps（Mac）。
- スマホ実機：2026-10-12 に確認済み（重さ・操作感・BGMと効果音の大きさ・告知動画の音）。
